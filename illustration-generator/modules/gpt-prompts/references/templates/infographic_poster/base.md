# 科技信息图海报模板

基于产品发布会级信息图的视觉风格，适用于任何主题的全解析海报。

## 风格参数

| 项目 | 值 |
|------|------|
| 比例 | 9:16（竖版手机屏） |
| 背景 | 纯白 #FFFFFF |
| 主色 | 亮红 #E74C3C |
| 辅助 | 灰 #888, 蓝 #3498DB, 金 #D4A017, 银 #95A5A6 |
| 字体 | 无衬线黑体，现代sans-serif |
| 卡片 | 圆角白色，微阴影 |

## 完整布局结构（6个Section）

### 顶部 Header
- 左上：大号粗体黑色标题 `{{TITLE}}`，灰色副标题 `{{SUBTITLE}}`，红点 + `{{DATE}}`
- 右上：主题相关的红色线稿插图（风景/人物/建筑），下方手写风格署名 `{{SIGNATURE}}`，小字 `{{SIGNATURE_ROLE}}`

### 数据行 Stats Row
5个圆角白色卡片横向排列，大号粗体数字 + 灰色小标签 + 红色下划线：
```
{{STAT_1_VALUE}} | {{STAT_1_LABEL}}
{{STAT_2_VALUE}} | {{STAT_2_LABEL}}
{{STAT_3_VALUE}} | {{STAT_3_LABEL}}
{{STAT_4_VALUE}} | {{STAT_4_LABEL}}
{{STAT_5_VALUE}} | {{STAT_5_LABEL}}
```

### Section 01: 核心特点
4个圆角白色卡片，彩色编号圆圈 + 粗体标题 + 灰色副标题：
- 01 🔴 `{{FEATURE_1_TITLE}}` — `{{FEATURE_1_DESC}}`
- 02 🔵 `{{FEATURE_2_TITLE}}` — `{{FEATURE_2_DESC}}`
- 03 🟡 `{{FEATURE_3_TITLE}}` — `{{FEATURE_3_DESC}}`
- 04 ⚪ `{{FEATURE_4_TITLE}}` — `{{FEATURE_4_DESC}}`

### Section 02: 优势与挑战
左右双栏，中间白色圆形 VS 分隔：
- **左栏**（浅红底，红色左边框）：3个红色✓要点
- **右栏**（浅灰底，灰色右边框）：3个灰色●要点

### Section 03: 流程/阶段
4个圆角白色卡片，红色→箭头连接：
- 卡片1 → 卡片2 → 卡片3 → 卡片4

### Section 04: 应用场景/实用信息
5个圆角白色卡片，红色图标 + 标题 + 副标题

### Section 05: 评价/引用
两张并排引用卡片，红色引号图标 + 引用文字 + 署名

### 底部 Footer
- 标题：`{{FOOTER_TITLE}}`
- 粗体slogan：`{{SLOGAN}}`
- 红色圆角CTA按钮（白字+箭头）：`{{CTA_TEXT}}`
- 右下：品牌logo/图标 + 品牌名

## 使用方式

### 方式一：纯prompt生成
用上面的模板结构填入具体内容，直接文生图。适合全新主题。

### 方式二：edit模式（推荐）
1. 先用纯prompt生成一版完整的v1
2. 挑选最满意的版本作为基底
3. 用 `--image` edit模式微调局部（如换右上角插图、调整某section内容）
4. edit模式比纯prompt更能保持整体结构稳定

### 方式三：参考图 + edit
1. 找一张风格满意的参考信息图
2. 用 `--image` 加参考图 + prompt描述内容变化
3. 模型会自动保持参考图的结构和风格

## 实战经验

1. **内容密度要克制**：6个section已经是上限，再多就糊。每个section内容越精炼越好
2. **所有文字在prompt中明确写出**：不要让模型自由发挥文字内容，必须逐字指定
3. **右上角插图是灵魂**：用主题相关的红色线稿（风景/建筑/人物），比通用图标高级很多
4. **竖版9:16适合手机传播**：小红书/朋友圈直接发，横版16:9信息密度不够
5. **不要过度描述视觉细节**：模型对布局结构的理解比颜色渐变强，优先描述结构
6. **edit模式微调比重生成稳定**：一旦找到满意的结构，用edit改内容比重新生成风险小
7. **第一版通常文字可读性差**：可能需要2-3次迭代才能让文字清晰可读
