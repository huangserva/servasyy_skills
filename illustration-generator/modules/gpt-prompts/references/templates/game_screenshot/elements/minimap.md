# HUD Element: Minimap

## 通用版本

```
Top Right Corner — Minimap:
- Circular minimap showing surrounding area
- Player position marker (center)
- NPC markers (green), enemy markers (red), objective marker (yellow)
- Cardinal direction indicators
```

## 仙侠MMO版本

```
Top Right Corner — Minimap:
- Circular parchment-style minimap with Chinese calligraphy-style labels
- Player dot (golden), NPC dots (blue), boss dot (large red pulsing)
- Nearby area name displayed above minimap
- Quest objective arrow pointing toward target
- Auto-path indicator line
```

## 赛博朋克版本

```
Top Right — Mini-map:
- Circular holographic minimap with scan-line effect
- Street grid layout, neon-colored markers
- Enemy markers (red triangles), objective marker (yellow diamond)
- GPS route line in cyan
- "威胁检测: 活跃" (Threat Detection: Active) label
```

## 使用说明

- 小地图通常在右上角，但也有左下角的变体
- 标记颜色约定：绿色=友方，红色=敌方，黄色=目标，蓝色=NPC
- 仙侠用古风/羊皮纸质感，赛博朋克用全息/扫描线质感
