# 黄总的统一生图与提示词收藏

这是 Codex 中唯一的个人通用生图入口。原来独立的个人静态生图/提示词技能已归为 `modules/` 下的参考指南，不再重复注册。系统内置 imagegen 是工具说明层；视频、图片归档等独立任务不被本入口接管。

## 分类选择

先保留当前对话已确定的主体、用途、比例、数量、文字、风格、参考图职责和输出路径。依据最终交付物选一项主分类，只读取相关资料；不要求用户记住技能名。

| 分类 | 适用任务 | 按需读取 |
| --- | --- | --- |
| 文章配图 | 文章插图、横版封面、多风格比较 | [文章配图](references/article.md)，复用 Claude 20 种风格库，以实际查询为准 |
| 海报与商业设计 | 海报、信息图、电商、品牌、界面、出版物、手帐 | [通用提示词与模板](modules/gpt-prompts/GUIDE.md)；归藏社交卡片/公众号封面对使用 [归藏原工作流](modules/guizang-social-card-skill/GUIDE.md)；出图后端默认 [Qwen-Image 2.1 本地](modules/qwen-image-21-t2i/GUIDE.md) |
| 人物与角色 | 生活摄影、角色扮演、夏季人物照片 | 普通生活抓拍：[生活摄影](modules/vibeshot-candid-photography/GUIDE.md)；指定成年角色：[角色摄影](modules/character-candid-photography/GUIDE.md)；夏季泳装伴侣/朋友视角：[夏季摄影](modules/summer-boyfriend-pov/GUIDE.md)；其余用通用模板 |
| 绘画与风格探索 | 插画、国画、油画、稀有风格、东方幻想 | 常规绘画用通用风格库；[稀有风格探索](modules/rare-style-explorer/GUIDE.md)；[东方神怪工笔水墨](modules/shan-ze-school/GUIDE.md) |
| 场景与游戏 | 游戏截图、影视感场景、建筑、历史、叙事 | [通用提示词与模板](modules/gpt-prompts/GUIDE.md)，游戏可拼装界面组件 |
| 编辑与连续画面 | 局部修改、多参考图合成、连续角色一致性 | [编辑与后端](references/backends.md)；多阶段角色连续性用 [连续画面工作流](modules/cinematic-i2i-continuity/GUIDE.md) |
| 提示词收藏 | 收藏、检索、复用、学习认可的图片风格 | [收藏规则](references/collection.md)，保留原始提示词、分类和验证状态 |

“列出风格”先展示大类和最相关的几种视觉差异；用户要全部再展开。文章的三种推荐沿用原系统；“剩下几种”指上一轮未做的选项，不重新定义。分类不等于画风，不把 模板类别说成画风。

## 共同工作方式

1. 用户只要提示词时，只交付提示词；请求出图时完成出图与展示。已明确的创作选择直接执行，不因为旧指南写了确认步骤就重复询问。
2. 先查相关收藏/模板，再按需求改写。仅参考历史案例的创作内容和用户反馈；旧耗时、模型能力、服务状态与自评不能当成当前保证。来源不明的“官方推荐”只是历史笔记。
3. 模块中的相对路径以该模块目录为基准。旧技能名当分类别名处理；不要重新安装独立入口。旧路径兼容链接仅供已有脚本和素材引用。
4. 生图使用 [后端选择规则](references/backends.md)。黄总已选择自己的系统；保留既有文章与 GPT 图像后端，不悄悄换服务或模型。编辑任务遵守当前宿主的工具要求；宿主明确要求内置编辑工具时，使用内置工具并说明实际后端。
5. 检查参考图再编辑，为各张参考指定身份、风格、服装、布局等职责。保留用户要求的媒介、人物、文字与比例。
6. 检查实际图片尺寸、文字、构图、身份和主体完整性，保存原图与完整提示词。分辨率档位不代表精确像素尺寸；不把只检查过脚本称为生图实测。
7. 用户认可结果或明确要求收藏时按收藏规则写入。未经认可的图可记录为待验证，不能自动进入认可案例。默认在当前对话展示图片；旧指南里发飞书、发布或归档的步骤不构成授权。

本轮统一只组织个人图片知识与入口，不修改系统技能。备份和来源见 [迁移记录](references/migration.json)。
